# @darkdeploy/core

Core mathematical and evaluation engine for **DarkDeploy**.

## Installation

```bash
npm install @darkdeploy/core
```

## Features

- **Deterministic Hashing**: SHA-1 hex bucket hashing for percentage rollouts.
- **Rule Engine**: Fast attribute-based rule matching (`EQUALS`, `IN`, `CONTAINS`, `GREATER_THAN`).
- **Statistical Significance**: Two-proportion z-test calculation with $p$-value and confidence intervals.
- **Variant Allocation**: Deterministic distribution across multi-variant A/B experiments.
